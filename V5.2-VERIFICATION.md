# MEME.RADAR V5.2 — change and verification record

## Applied source changes

- `meme-radar-v5-risk-engine.mjs`
  - Position size: 6% of equity base; score 80–89 uses 0.8x, score 90+ uses 1.0x; scores below 80 and non-RESEARCH tiers return zero.
  - Maximum size is capped at 0.35% of pool liquidity and available cash.
  - Daily drawdown breaker is -12% with a 12-hour new-entry pause.
  - Runner trail above +100% is 20%; emergency liquidity thresholds are >35% from entry and >20% between checks.
- `meme-radar-v5-intelligence.mjs`
  - Enforces minimum 15-minute pair age, 5-minute buy ratio >=55%, 1-hour buy ratio >=52%, and rejects 5-minute +35% / 1-hour +150% spikes.
  - Optional previous-liquidity check rejects a decline greater than 5%; unknown prior liquidity fails when the caller requires stability.
- `meme-radar-bot.mjs`
  - Passes persisted previous-pair liquidity into the required stability gate and aligns the sizing/drawdown configuration.
  - The first observation has no previous liquidity; it is recorded as a baseline and must be seen again before passing this gate.
- `index.html`
  - V5 research table now uses DOM elements and `textContent` rather than interpolating research metadata into `innerHTML`.
- `memeradar-state-api/worker.js`
  - Public partial-exit metadata is reduced to bounded, typed fields and sanitized text.
- `meme-radar-v5-risk-engine.test.mjs` and `meme-radar-v5-intelligence.test.mjs`
  - Updated sizing/threshold assertions and added discovery fail-closed regression tests.
